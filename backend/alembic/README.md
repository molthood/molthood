# Migrations

Alembic is scaffolded but **no migration has been generated**. Phase 3 opens no
database connection, so there is nothing to migrate against yet.

The models in `app/models/` are complete and registered on `Base.metadata`, so
the first revision can be autogenerated as soon as a database exists:

```bash
# with PostgreSQL reachable at DATABASE_URL
alembic revision --autogenerate -m "initial schema"
alembic upgrade head
```

To inspect the SQL without a database:

```bash
alembic upgrade head --sql
```

`env.py` reads `DATABASE_URL` from application settings, not from `alembic.ini`.
